# L 均衡切割 (Length-Balanced Cuts)

来源：CCPC 荆州站正式赛（2026-11-15），题面见 [contests/ccpc-round-jingzhou/formal/ccpc_jingzhou_formal.md#l-均衡切割](../../contests/ccpc-round-jingzhou/formal/ccpc_jingzhou_formal.md)。

Bobo 正在上木工课。今天的任务是把一根长度为 X 的木条切成若干根短木条，使每根木条的长度都不超过 B。

每次切割操作，Bobo 可以选择当前任意一根木条，将它切成两根长度差不超过 D 的木条。切出的木条还可以继续切割。所有木料都必须保留，也不能将木条重新拼接。

请你帮 Bobo 求出完成任务所需的最少操作次数。如果原木条的长度已经不超过 B，则答案为 0。

## 输入格式

第一行包含一个整数 T (1 ≤ T ≤ 1000)，表示独立测试数据的组数。

接下来 T 行，每行包含三个整数 X, B, D (1 ≤ X, B, D ≤ 10^9)。

## 输出格式

对于每组测试数据，输出一行一个整数，表示最少操作次数。

## 样例输入 1

```text
4
1 1 1
6 2 1
6 2 2
9 3 2
```

## 样例输出 1

```text
0
3
2
3
```

## 样例输入 2

```text
3
18 3 2
10 20 1
1000000000 1 1000000000
```

## 样例输出 2

```text
6
0
999999999
```

## 样例说明

- X = 6, B = 2, D = 1：先切成两根长度为 3 的木条，再将它们分别切成长为 1.5 和 1.5 的木条，共需 3 次操作。
- X = 6, B = 2, D = 2：可以先切成长为 2 和 4 的木条，再将长度为 4 的木条切成两根长度为 2 的木条，共需 2 次操作。
