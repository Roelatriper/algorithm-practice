# 多次区间求和

给定 n 个整数，之后有 q 次查询。每次给出 l、r，求第 l 项到第 r 项的总和，两端都包含。查询过程中数组不会修改，下标从 1 开始。

## 输入

第一行 n、q，满足 1 <= n,q <= 100000。

第二行 n 个整数 a[i]，满足 -1000 <= a[i] <= 1000。

随后 q 行，每行 l、r，满足 1 <= l <= r <= n。

## 输出

每次查询输出一行区间和，共 q 行。

## 样例

```text
5 3
2 5 1 4 3
2 4
1 5
3 3
```

```text
10
15
1
```
