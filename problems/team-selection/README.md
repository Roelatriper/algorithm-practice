- 2027 年选拔预计在 3 月左右举行，形式应为网赛；确切信息预计寒假公布。

## 作答文件约定

开始作答某题时，为该题建立同名目录并保留原题面，例如：

```text
题目名/
├── statement.md
├── attempt.cpp
├── solution.cpp
├── review.md
└── tests/
```

真实首次作答写入 `attempt.cpp`，不使用参考代码覆盖；编译产物统一放在仓库根目录的 `.build/`。
