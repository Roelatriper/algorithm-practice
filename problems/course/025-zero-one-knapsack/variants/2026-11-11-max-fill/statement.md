# 不超过容量时尽量装满

有 `n` 件物品，每件仅有一件，第 `i` 件重量为 `w[i]`。背包容量为 `W`，求不超过 `W` 的最大总重量。

## 输入

第一行 `n W`；若 `n>0`，接下来给出 `n` 个物品重量，空格或换行分隔。

## 输出

一个整数：最大总重量。

## 样例

输入：

```text
3 7
6 4 3
```

输出：

```text
7
```

## 数据范围与要求

`0 <= n <= 100`，`0 <= W <= 10000`，`1 <= w[i] <= 10000`。请先解释它与 0/1 背包的状态对应关系，再闭卷独立实现并只输出一行答案。测试须覆盖 `n=0`、`W=0`、所有物品放不下，以及 `6,4,3` 在容量 `7` 下不能只选单件最重物品的反例。作为 025 的轻微迁移，不覆盖旧作答。
