# 0/1 背包

有一个容量为 `W` 的背包和 `n` 件物品。第 `i` 件物品的重量为 `weight[i]`，价值为 `value[i]`。

每件物品最多只能选择一次。所选物品的总重量不能超过 `W`。请输出能够取得的最大总价值。

## 输入

第一行两个整数 `n`、`W`。

接下来 `n` 行，每行两个整数 `weight[i]`、`value[i]`。

## 输出

一个整数，表示不超过背包容量时能够取得的最大总价值。

## 样例

输入：

```text
3 5
2 3
3 4
4 5
```

输出：

```text
7
```

可以选择前两件物品，总重量为 `5`，总价值为 `7`。

## 数据范围

- `0 <= n <= 100`
- `0 <= W <= 10000`
- `1 <= weight[i] <= 10000`
- `0 <= value[i] <= 1000000000`
- 答案保证在有符号 64 位整数范围内。

## 作答要求

先不要写代码。请先写出：

1. 二维状态 `dp[i][c]` 的准确含义；
2. 第 `i` 件物品不选和选择时分别从哪个状态转移；
3. 初始状态与物品放不下时的处理；
4. 压缩成一维后容量循环的方向，以及为什么这个方向不会重复使用当前物品。

四项确认后，再使用一维 `dp` 独立编码并报告独立用时。使用 C++03 兼容语法。
