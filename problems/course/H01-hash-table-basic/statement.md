# H01 基础题：实现简化的频次哈希表

## 任务

固定使用 7 个桶，桶编号为 `0` 到 `6`。读入 `n` 个整数 key。每读到一个 key，就将它的出现次数加 1。随后读入 `q` 个查询 key，输出每个 key 在前 `n` 个整数中出现的次数；从未出现的 key 输出 `0`。

请手写拉链哈希表。每个桶用 `vector<Entry>` 存记录，`Entry` 至少包含完整 `key` 和出现次数。不得用 `map`、`unordered_map` 或直接开一个覆盖整个 key 值域的数组代替。

## 输入格式

第一行两个整数 `n q`。

第二行有 `n` 个整数。若 `n=0`，这一行为空或省略。

第三行有 `q` 个整数查询 key。

## 输出格式

输出 `q` 行，每行一个查询结果。`q=0` 时不输出任何行。

## 数据范围

- `0 <= n,q <= 100000`
- 每个 key 为有符号 32 位整数
- 出现次数不超过 100000

## 例子

输入：

```text
5 5
5 12 -2 5 0
5 12 -2 0 19
```

输出：

```text
2
1
1
1
0
```

## 实现要求

- 先计算 bucket，再在桶内逐条比较完整 key。
- bucket 计算必须正确处理负 key，不能产生负下标；不要对 `INT_MIN` 取负数求绝对值。
- 同一个 key 再次出现时更新其次数；另一个 key 即使落入同一个桶，也要作为独立记录保留。
- 查询不存在的 key 返回 0。
- 使用 C++03 兼容语法。

## 学生测试

提交代码时另外给出至少 4 组自主测试的完整输入、完整输出和测试理由。总覆盖还须包含：空表、零 key、负 key、重复 key、不同 key 同桶、不存在 key、集中碰撞与最大规模附近的数据。可在一组测试中覆盖多个条件。
