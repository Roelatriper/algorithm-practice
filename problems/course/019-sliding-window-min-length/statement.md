# 和至少为目标值的最短连续子数组

给定一个由正整数组成的数组和一个正整数 `target`，求元素和大于等于 `target` 的最短非空连续子数组长度。

如果不存在符合条件的连续子数组，输出 `0`。

## 输入

第一行两个整数 `n`、`target`，满足 `1 <= n <= 100000`，`1 <= target <= 1000000000`。

第二行 `n` 个正整数 `a[i]`，满足 `1 <= a[i] <= 10000`。

题目范围保证整个数组的和可以使用普通 `int` 保存。

## 输出

输出一个整数，表示最短合法连续子数组的长度；不存在时输出 `0`。

## 样例 1

```text
6 7
2 3 1 2 4 3
```

```text
2
```

其中最后两个元素 `[4,3]` 的和为 `7`。

## 样例 2

```text
4 20
1 2 3 4
```

```text
0
```
