# 和不超过上限的最长连续子数组

给定一个由正整数组成的数组和一个正整数 `limit`，求元素和不超过 `limit` 的最长非空连续子数组长度。

如果连一个元素都无法选取，输出 `0`。

## 输入

第一行两个整数 `n`、`limit`，满足 `1 <= n <= 100000`，`1 <= limit <= 1000000000`。

第二行 `n` 个正整数 `a[i]`，满足 `1 <= a[i] <= 10000`。

题目范围保证整个数组的和可以使用普通 `int` 保存。

## 输出

输出一个整数，表示最长合法连续子数组的长度；不存在时输出 `0`。

## 样例 1

```text
5 5
2 1 3 1 1
```

```text
3
```

例如 `[1,3,1]` 的和为 `5`，长度为 `3`。

## 样例 2

```text
3 2
3 4 5
```

```text
0
```
