# 多次区间加法

给定一个长度为 `n` 的整数数组，之后进行 `m` 次修改。

每次修改给出 `l`、`r`、`k`，表示把第 `l` 项到第 `r` 项（两端都包含）全部加上 `k`。

所有修改完成后，输出最终数组。

## 输入

第一行两个整数 `n`、`m`，满足 `1 <= n,m <= 100000`。

第二行 `n` 个整数 `a[i]`，满足 `-1000 <= a[i] <= 1000`。

随后 `m` 行，每行三个整数 `l`、`r`、`k`，满足：

- `1 <= l <= r <= n`
- `-1000 <= k <= 1000`

保证所有修改完成后，每个元素都在普通 32 位 `int` 范围内。

## 输出

输出一行 `n` 个整数，依次表示最终数组。相邻整数之间用一个空格分隔。

## 样例输入

```text
5 3
1 2 3 4 5
1 3 2
2 5 -1
4 4 10
```

## 样例输出

```text
3 3 4 13 4
```
