# 差分单点查询迁移：学生自主测试

学生于2026-11-04提供三组输入、预期与用途；下方只把空格分隔的描述排成题面输入格式，数值和顺序未改。实际运行由Tutor执行，学生未报告本人运行结果。

## 1. 最小边界

输入：

```text
1 0 1
1
1
```

学生预期：

```text
1
```

用途：最小数组、零次修改、单次查询。Tutor实际输出 `1`，符合预期。

## 2. 单点修改

输入：

```text
2 1 2
1 2
1 1 -1
1
2
```

学生预期：

```text
0
2
```

用途：只修改一项，分别查询修改位置及未修改位置。Tutor实际输出 `0/2`，符合预期。

## 3. 反序查询

输入：

```text
3 2 2
1 3 5
1 3 -2
2 3 2
3
1
```

学生预期：

```text
5
-1
```

用途：两次重叠区间修改后，先查询较大位置再查询较小位置。最终数组为 `-1 3 5`；Tutor实际输出 `5/-1`，符合预期。

三组均在严格C++17加ASan/UBSan构建下运行通过。自主设计帮助等级0；实际运行是教师证据，不能记为学生本人执行。
