# 多次区间修改后的单点查询

有一个长度为 `n` 的整数数组 `a`。先执行 `m` 次区间加法，再回答 `q` 次查询。

一次修改给出 `l r k`：把第 `l` 项到第 `r` 项（两端都包含）全部加上 `k`。所有修改完成以后，每次查询给出一个位置 `p`，请输出最终数组的第 `p` 项。查询不会修改数组。

## 输入

第一行三个整数 `n m q`。

第二行 `n` 个整数 `a[1]` 到 `a[n]`。

随后 `m` 行，每行三个整数 `l r k`。

最后 `q` 行，每行一个整数 `p`。

## 输出

按查询顺序输出 `q` 行，每行一个整数，表示对应位置在全部修改后的值。

## 样例

输入：

```text
5 3 3
1 2 3 4 5
1 3 2
2 5 -1
4 4 10
1
3
4
```

输出：

```text
3
4
13
```

## 数据范围

- `1 <= n, q <= 100000`，`0 <= m <= 100000`。
- `-1000000000 <= a[i], k <= 1000000000`。
- `1 <= l <= r <= n`，`1 <= p <= n`。
- 所有中间值及答案均保证在有符号64位整数范围内。
