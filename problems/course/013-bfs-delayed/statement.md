# BFS 延迟迁移：给定坐标的迷宫最短路

本题是 2026-09-30 BFS 学习后的延迟验证。先关闭以前的作答与参考代码，独立完成；记录实际编码用时和自主测试。

## 题目

给定一个 `rows` 行、`cols` 列的地图，`.` 表示可以走的格子，`#` 表示墙。每次可以向上、下、左、右走一格，不能越界或进入墙。

起点、终点由坐标给出。求从起点到终点的最少移动次数；无法到达输出 `-1`。起终点可以相同。

## 输入

第一行是 `rows cols`，满足 `1 <= rows, cols <= 100`。

接下来 `rows` 行，每行恰好 `cols` 个字符，只包含 `.` 和 `#`。

最后一行是 `sr sc tr tc`，依次表示起点行、起点列、终点行、终点列。坐标从 `0` 开始，保证坐标合法，且起点与终点都是可走格子。

## 输出

一个整数，表示最少移动次数，或 `-1`。

## 样例

输入：

```text
3 5
..#..
..#..
.....
1 0 1 4
```

输出：

```text
6
```
