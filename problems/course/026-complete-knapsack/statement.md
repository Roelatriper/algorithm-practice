# 完全背包

有一个容量为 `W` 的背包和 `n` 种物品。第 `i` 种物品的重量为 `weight[i]`，价值为 `value[i]`，每种物品都有足够多件，可以选择任意次。

所选物品的总重量不能超过 `W`。请输出能够取得的最大总价值。

## 输入

第一行两个整数 `n`、`W`。

接下来 `n` 行，每行两个整数 `weight[i]`、`value[i]`。

## 输出

一个整数，表示不超过背包容量时能够取得的最大总价值。

## 样例

输入：

```text
2 7
2 3
3 4
```

输出：

```text
10
```

可以选择两件重量为 `2` 的物品和一件重量为 `3` 的物品，总重量为 `7`，总价值为 `10`。

## 数据范围

- `0 <= n <= 100`
- `0 <= W <= 10000`
- `1 <= weight[i] <= 10000`
- `0 <= value[i] <= 1000000000`
- 答案保证在有符号 64 位整数范围内。

## 作答要求

本题在第 2 课次开始前不要求提前作答。开始作答时先说明：

1. 与 0/1 背包相比，唯一改变的选择规则是什么；
2. 压缩成一维后容量循环的方向；
3. 为什么这个方向允许当前物品被重复选择。

确认后再独立编码并报告独立用时。使用 C++03 兼容语法。
