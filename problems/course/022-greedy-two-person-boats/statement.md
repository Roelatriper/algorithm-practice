# 限重两人配对

有 `n` 个人需要乘船，每艘船最多坐两人，且两人的体重之和不能超过 `W`。第 `i` 个人的体重为 `a[i]`，每个人都必须上船。

求最少需要多少艘船。

## 输入

第一行两个整数 `n` 和 `W`。

第二行 `n` 个正整数 `a[i]`。

## 输出

一个整数，表示最少需要的船数。

## 数据范围

- `1 <= n <= 100000`
- `1 <= a[i] <= W <= 1000000000`

## 作答要求

1. 先考虑当前最重的人，并说明哪些情况属于被迫选择。
2. 若当前选择不是唯一的，说明为什么可以调整某个最优方案而不增加船数。
3. 区分“双指针怎样移动”和“为什么这样移动正确”。
4. 给出能区分 `< W` 与 `<= W` 的边界测试，使用 C++03 兼容语法并报告独立用时。
