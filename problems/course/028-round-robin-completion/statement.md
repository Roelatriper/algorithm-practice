# 轮转任务的完成顺序

有 `n` 个任务，编号为 `1` 到 `n`，按编号顺序排队。第 `i` 个任务需要处理 `t[i]` 次。每轮只处理队首任务一次：如果它还有剩余次数，就把它放到队尾；如果它刚好完成，就让它离开队伍，并记录它的编号。

请输出所有任务完成的顺序。

## 输入

第一行一个整数 `n`。若 `n>0`，后面给出 `n` 个整数 `t[1]` 到 `t[n]`，空格或换行分隔；若 `n=0`，没有后续数据。

## 输出

若 `n=0`，输出 `EMPTY`。否则在一行中按完成顺序输出 `n` 个任务编号，相邻编号之间用一个空格分隔。

## 样例

输入：

```text
3
2 1 3
```

输出：

```text
2 1 3
```

## 数据范围

- `0 <= n <= 100000`。
- `1 <= t[i] <= 10`。

## 作答要求

先手推样例的前几轮，说明队列保存什么、一次处理后何时重新入队，再独立实现并报告用时。自选测试至少考虑空队列与同一个任务多次回队尾。使用 C++03 兼容语法。
