# 用最少的点覆盖区间

给出 `n` 个闭区间 `[l[i], r[i]]`。你可以在整数数轴上选若干个点。若某区间内至少有一个被选点，就称它被覆盖。求覆盖所有区间所需的最少点数。

## 输入

第一行一个整数 `n`。接下来 `n` 行，每行两个整数 `l[i] r[i]`。

## 输出

一行一个整数，表示最少点数。

## 样例

输入：

```text
4
1 3
2 5
3 6
7 9
```

输出：

```text
2
```

## 数据范围

- `0 <= n <= 100000`。
- `-1000000000 <= l[i] <= r[i] <= 1000000000`。

## 独立作答要求

先提出选择规则，再用一个小反例检验“总选当前区间左端点”。请说明选了一个点后，哪些区间已确定覆盖；尝试用交换论证说明你的选择不会比某个最优方案差。编码后自测空集合、单点区间、端点恰好相接、互不相交及包含关系，写出精确预期与理由。使用 C++03 兼容语法，报告独立用时。
