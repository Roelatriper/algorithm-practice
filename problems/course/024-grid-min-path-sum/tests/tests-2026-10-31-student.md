# 学生自主测试：网格最小路径代价

- 日期：2026-10-31
- 学生使用紧凑格式给出输入、预期和用途；教师只展开为可运行格式。
- 第1组初答预期为1，经测试帮助1指出起点代价为0且起终点重合，学生确认订正为0；第2、3组初答正确。

```text
1 1
0
```

```text

```

