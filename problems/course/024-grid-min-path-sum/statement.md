# 网格最小路径代价

给定一个 `n` 行 `m` 列的非负整数网格。你从左上角 `(1,1)` 出发，每次只能向右或向下移动一格，直到右下角 `(n,m)`。

进入每个格子都要支付该格子的代价，起点和终点也计入。请输出一条合法路径的最小总代价。

## 输入

第一行两个整数 `n`、`m`。

接下来 `n` 行，每行 `m` 个非负整数，表示各格子的代价。

## 输出

一个整数，表示从左上角到右下角的最小总代价。

## 样例

输入：

```text
3 4
1 3 1 5
2 1 4 2
5 2 1 1
```

输出：

```text
8
```

## 数据范围

- `1 <= n, m <= 1000`
- `0 <= cost[i][j] <= 1000000`
- 答案保证在有符号 64 位整数范围内。

## 作答要求

1. 先写出二维状态含义、转移、初值和计算顺序。
2. 明确说明第一行、第一列如何处理，不能访问网格外下标。
3. 使用 C++03 兼容语法，报告独立用时。
4. 本题在第 2 课次开始前不要求提前作答。
