# 带代价上楼梯

有一段编号为 `0` 到 `n` 的楼梯。你从第 `0` 级出发，每次可以向上走 `1` 级或 `2` 级。

到达第 `i` 级（`1 <= i <= n`）时，需要支付 `cost[i]`。第 `0` 级不需要付费。

请输出到达第 `n` 级所需的最小总代价。

## 输入

第一行一个整数 `n`。

第二行 `n` 个非负整数，依次为 `cost[1]` 到 `cost[n]`。

## 输出

一个整数，表示到达第 `n` 级的最小总代价。

## 样例

输入：

```text
5
4 1 7 3 2
```

输出：

```text
6
```

一种最优走法是 `0 -> 2 -> 4 -> 5`，总代价为 `1 + 3 + 2 = 6`。

## 数据范围

- `1 <= n <= 100000`
- `0 <= cost[i] <= 1000000000`
- 答案保证在有符号 64 位整数范围内。

## 作答要求

先不要写代码。请先写出：

1. `dp[i]` 的准确含义；
2. 到达第 `i` 级的最后一步可能来自哪里；
3. 状态转移；
4. 初始状态；
5. 计算顺序。

五项确认后再开始独立编码，并报告独立用时。使用 C++03 兼容语法。
