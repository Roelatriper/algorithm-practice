# 多次查询区间内的达标人数

给定 `n` 名同学的成绩，编号从 1 开始。成绩不少于 60 分算达标。

之后有 `q` 次查询。每次给出 `l`、`r`，请输出编号从 `l` 到 `r`（两端都包含）的同学中，有多少人成绩达标。

查询过程中成绩不会修改。

## 输入

第一行两个整数 `n`、`q`，满足 `1 <= n,q <= 100000`。

第二行 `n` 个整数 `a[i]`，满足 `0 <= a[i] <= 100`。

随后 `q` 行，每行两个整数 `l`、`r`，满足 `1 <= l <= r <= n`。

## 输出

每次查询输出一行答案，共 `q` 行。

## 样例输入

```text
7 4
59 60 75 20 100 60 58
1 7
2 3
4 6
1 1
```

## 样例输出

```text
4
2
2
0
```
