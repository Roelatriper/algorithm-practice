# 统计和不超过目标值的数对

给定一个按非递减顺序排列的整数数组和一个整数 `target`，统计有多少对不同位置 `(i, j)` 满足：

```text
i < j
a[i] + a[j] <= target
```

## 输入

第一行两个整数 `n`、`target`，其中 `2 <= n <= 100000`。

第二行有 `n` 个按非递减顺序排列的整数。数组元素及 `target` 的范围保证两个数组元素之和能用普通 `int` 保存。

## 输出

输出一个整数，表示合法数对的数量。

## 作答要求

- 使用相向双指针，时间复杂度为 `O(n)`。
- 同一个位置不能使用两次。
- 计数器使用 `long long`。
- 使用 C++03 风格语法，报告独立用时，并提供至少三组自主测试。
