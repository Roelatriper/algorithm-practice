# H03 轻微迁移：第一个重复编号

## 任务

给出一个按顺序排列的整数序列。请使用自己实现的简化拉链哈希表，找出**第一个让某个编号第二次出现的位置**，输出该位置（从 1 开始）。如果整个序列没有重复编号，输出 `0`。

例如 `8 3 8 3` 中，第 3 个数 `8` 是第一个第二次出现的编号，因此输出 `3`。

## 输入格式

第一行一个整数 `n`。

第二行有 `n` 个有符号 32 位整数。

## 输出格式

输出一个整数：第一个重复出现位置；若无重复，输出 `0`。

## 数据范围

- `0 <= n <= 100000`
- 每个整数为有符号 32 位整数

## 例子

输入：

```text
6
-1 4 7 4 -1 9
```

输出：

```text
4
```

## 学生测试

至少自行设计 3 组测试，覆盖空序列、全不重复、重复值在开头或末尾、负数与零，以及不同 key 同桶但序列仍无重复的情况。给出完整输入、预期输出和理由。
