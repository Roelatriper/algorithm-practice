# H02 应用题：整数频次统计与查询

## 任务

给出一批整数编号和若干询问。对每个询问，输出该编号在输入批次中出现的次数。输入中的编号可能为负数、为零、稀疏分布，也可能很大；请用自己实现的简化拉链哈希表完成统计，不使用 `map` 或 `unordered_map`。

本题的目标是把题意翻译为映射：`key = 编号`，`value = 出现次数`。同一编号再次出现时，增加它已有的次数。

## 输入格式

第一行一个整数 `n`，表示编号个数。

第二行有 `n` 个有符号 32 位整数。

第三行一个整数 `q`，表示询问数。

第四行有 `q` 个有符号 32 位整数。

## 输出格式

对每个询问输出一行出现次数；未出现的编号输出 `0`。

## 数据范围

- `0 <= n,q <= 100000`
- 编号为有符号 32 位整数

## 例子

输入：

```text
7
-5 0 12 -5 19 12 -5
5
-5 12 0 19 1
```

输出：

```text
3
2
1
1
0
```

## 学生测试

至少自行设计 3 组测试，给出完整输入、预期输出和理由。覆盖 `n=0`、重复编号、负数和零、未出现查询，以及至少一组发生 bucket 碰撞的数据。说明你选的桶数和负键如何映射到合法桶。
