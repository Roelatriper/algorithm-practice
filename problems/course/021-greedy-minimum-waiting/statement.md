# 最小总等待时间

有 `n` 个人等待同一个服务窗口。第 `i` 个人办理业务需要 `t[i]` 分钟，你可以任意安排他们的先后顺序。

第一个人等待 `0` 分钟；后面每个人的等待时间等于排在他前面的所有办理时间之和。请输出所有人的最小等待时间总和。

## 输入

第一行一个整数 `n`。

第二行 `n` 个正整数 `t[i]`。

## 输出

一个整数，表示最小等待时间总和。

## 样例

输入：

```text
4
3 1 2 5
```

输出：

```text
10
```

按 `1,2,3,5` 的顺序办理时，四人的等待时间依次为 `0,1,3,6`，总和为 `10`。

## 数据范围

- `1 <= n <= 100000`
- `1 <= t[i] <= 100000`
- 答案保证在有符号 64 位整数范围内。

## 作答要求

1. 先写出选择规则，不要先交代码。
2. 用两个相邻且顺序不同的人，比较交换前后的总等待时间。
3. 给出一个反例，击穿一种你认为错误的排序策略。
4. 使用 C++03 兼容语法，报告独立用时。
