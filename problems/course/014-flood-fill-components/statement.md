# 统计可走区域数量与面积

> 2026-10-09：学生明确扩展功能，在连通块总数之后输出各块格子数。以下为当前有效要求；原练习仅要求总数。

给定 `rows` 行、`cols` 列的地图，`.` 表示可走格子，`#` 表示墙。只能向上、下、左、右移动一格，不能越界或进入墙。

能通过上述移动互相到达的可走格子属于同一个连通块。求地图中连通块的总数，以及各块包含的格子数（面积）。只在角上接触不算相连；没有可走格子时区域数为 0。

## 输入

第一行是 `rows cols`，满足 `1 <= rows, cols <= 100`。

接下来 `rows` 行，每行恰好 `cols` 个字符，只包含 `.` 和 `#`。本题没有指定起点或终点，也没有额外的坐标输入。

## 输出

第一行是一个整数 K，表示连通块数量。

随后 K 行，每行一个整数，表示一块区域的格子数。沿用当前程序的发现顺序：从上到下、从左到右扫描，按每块首次发现的顺序输出。K 为 0 时只输出第一行 0。

## 样例

输入：

```text
1 1
.
```

输出：

```text
1
1
```
