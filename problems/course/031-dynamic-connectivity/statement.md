# 动态连通性

有 `n` 个点，编号 `1..n`，初始互不连通。依次执行 `m` 个操作：

- `U a b`：在 a 与 b 之间增加一条连接。
- `Q a b`：询问 a 与 b 是否连通。连通允许经过其他点。

## 输入

第一行两个整数 `n m`，接下来 `m` 行各有一个操作。

## 输出

每个 `Q` 输出一行 `YES` 或 `NO`。

## 样例

输入：

```text
4 7
Q 1 4
U 1 2
U 3 4
Q 1 4
U 2 3
Q 1 4
Q 2 2
```

输出：

```text
NO
NO
YES
YES
```

## 数据范围与要求

`1 <= n <= 100000`，`0 <= m <= 200000`，`1 <= a,b <= n`。可能重复增加已有连接，也可能连接一个点到自身。先画小图并说出集合代表的含义，再独立编码。使用 C++03 兼容语法。
