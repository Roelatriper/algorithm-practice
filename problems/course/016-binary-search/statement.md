# 有序数组中的目标值

给定一个按非递减顺序排列的整数数组，之后有 q 次询问。每次给出一个整数 x，判断 x 是否在数组中出现。

数组在询问过程中不会修改；相同的值可能出现多次。

## 输入

第一行两个整数 n、q，满足 1 <= n,q <= 100000。

第二行 n 个整数 a[i]，满足 -1000000000 <= a[i] <= 1000000000，并保证 a[i] <= a[i+1]。

随后 q 行，每行一个整数 x，范围同数组元素。

## 输出

每次询问输出一行：如果 x 在数组中出现，输出 `YES`；否则输出 `NO`。

## 样例

```text
9 5
2 5 8 12 16 23 38 56 72
23
7
2
72
100
```

```text
YES
NO
YES
YES
NO
```
