# 自主测试记录

> 学生设计三组并给出预期。Tutor 发现学生把“不存在”的方向理解反了，给出 1 级语义提示和修正后的预期；学生表示能够理解且因用餐不再继续修改或运行。因此以下运行状态均为未报告。

## 测试 1：普通数组与两端方向

```text
3 2
1 2 3
0
3
```

学生原预期为 `-1、3`；正确预期为：

```text
1
3
```

理由：`0` 小于最小元素，因此第一个元素就不小于 `0`；查询 `3` 命中末项。

## 测试 2：单元素边界

```text
1 1
1
-1
```

学生原预期为 `-1`；正确预期为：

```text
1
```

理由：唯一元素 `1 >= -1`。若要验证无解，可将询问改为大于最大值的 `2`，此时预期才为 `-1`。

## 测试 3：上限规模规律

- `n=q=100000`，数组为 `1,2,...,100000`。
- 询问依次为 `-1,2,-3,4,...,-99999,100000`。
- 学生原预期为 `-1,2,-1,4,...`；正确规律为 `1,2,1,4,...,1,100000`。

理由：所有负数询问的第一个合法位置均为 1；正偶数询问的第一个合法位置等于该数本身。
