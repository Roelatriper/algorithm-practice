# 不选相邻位置的最大总和

有一列 `n` 个整数。你可以选择其中任意多个位置，但不能同时选择相邻的两个位置。也可以一个都不选。求所选整数的最大总和。

## 输入

第一行一个整数 `n`。若 `n>0`，第二行给出 `n` 个整数 `a[1] ... a[n]`。

## 输出

一行一个整数，表示最大总和。

## 样例

输入：

```text
5
2 7 9 3 1
```

输出：

```text
12
```

## 数据范围

- `0 <= n <= 100000`。
- `-1000000000 <= a[i] <= 1000000000`。
- 答案保证在有符号 64 位整数范围内。

## 独立作答要求

先判断“每次选当前最大数”是否总正确；若认为不正确，自造一个最小反例。随后用一句话定义所需状态，写出每个位置的“选/不选”来源、初值和计算顺序，再编码。至少自测 `n=0`、全负数、相邻大数和正负混合，并给出输入、精确预期与理由。使用 C++03 兼容语法，报告独立用时。
