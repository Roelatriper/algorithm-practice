# 定长连续子数组的最大和

给定一个长度为 `n` 的整数数组和一个窗口长度 `k`，求所有长度恰好为 `k` 的连续子数组中，最大的元素和。

## 输入

第一行两个整数 `n`、`k`，满足 `1 <= k <= n <= 100000`。
 
第二行 `n` 个整数 `a[i]`，满足 `-1000 <= a[i] <= 1000`。

题目范围保证任意连续子数组的和都可以使用普通 `int` 保存。

## 输出

输出一个整数，表示长度恰好为 `k` 的连续子数组的最大和。

## 样例

```text
6 3
2 1 5 1 3 2
```

```text
9
```
