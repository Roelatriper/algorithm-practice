# 从开头起的最长合法括号前缀

给定一串只含 `()[]{}` 的字符，求从第一个字符开始、整体括号匹配合法的最长前缀长度。空前缀也算合法，长度为 `0`。例如 `()([])` 的答案是 `6`，`()([)]` 的答案是 `2`。

## 输入

第一行是长度 `n`。若 `n>0`，第二行是一串长度为 `n` 的括号；若 `n=0`，没有第二行。

## 输出

输出一个整数：最长合法前缀长度。

## 数据范围与要求

`0 <= n <= 200000`。要求 `O(n)` 时间。先说明栈保存什么，以及怎样判断当前位置形成合法前缀；独立实现并自选边界测试。此题供 027 的七天迁移使用，最早 2026-11-14 18:36 后开始计入延迟证据。
