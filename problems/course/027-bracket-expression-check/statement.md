# 多种括号的表达式检查

给定一个只包含 `(`、`)`、`[`、`]`、`{`、`}` 的字符串。判断括号是否正确配对并嵌套。

正确配对要求：每个右括号与最近一个尚未闭合、且类型相同的左括号配对；最后不能留下未闭合的左括号。

## 输入

第一行一个整数 `n`，表示字符串长度。若 `n>0`，第二行给出长度恰为 `n` 的字符串；若 `n=0`，没有第二行。

## 输出

合法输出 `YES`，否则输出 `NO`。

## 样例 1

输入：

```text
6
([{}])
```

输出：

```text
YES
```

## 样例 2

输入：

```text
4
([)]
```

输出：

```text
NO
```

## 数据范围

- `0 <= n <= 200000`。
- 当 `n>0` 时，第二行保证恰有 `n` 个上述括号字符。

## 作答要求

先说明只计数为什么不够、容器中保存什么、遇到右括号时先检查什么。之后独立实现，报告用时，并提供输入、预期与目的明确的自选测试。使用 C++03 兼容语法。
