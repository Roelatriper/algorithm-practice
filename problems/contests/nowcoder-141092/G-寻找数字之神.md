# G - 寻找数字之神

来源：[牛客竞赛 141092](https://ac.nowcoder.com/acm/contest/141092/G)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒

空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M

64bit IO Format: %lld

## 题目描述

FuFuFu 和 v. 正在寻找传说中能够实现任何愿望的数字之神。

数字之神的本体是一个仅包含两位数字的正整数 $n$。为了伪装自己，他可以在左侧和右侧分别添加零位或多位数字。

举个栗子，如果数字之神是 $67$，$116722$ 可能是伪装后的数字之神，因为其中包含连续的 $67$；而 $161722$ 不可能，因为其中不存在连续的 $67$。

FuFuFu 知道数字之神的本体是 $n$。现在 v. 找到了一个正整数 $m$，他想知道 $m$ 是否可能为 $n$ 伪装后的数字。

换言之，判断 $n$ 是否为 $m$ 的连续子串。

## 输入描述

第一行输入两个整数 $n$ $(10 \leq n \leq 99)$，$m$ $(100 \leq m \leq 10^9)$，表示数字之神本体和 v. 找到的数。

## 输出描述

如果 $m$ 有可能是伪装过的数字之神，输出 $\texttt{YES}$；否则输出 $\texttt{NO}$。

## 示例1

### 输入

```text
67 116722
```

### 输出

```text
YES
```

## 示例2

### 输入

```text
67 161722
```

### 输出

```text
NO
```
