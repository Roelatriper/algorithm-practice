# M - 无尽咔咔（Hard Version）

来源：[牛客竞赛 141092](https://ac.nowcoder.com/acm/contest/141092/M)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒

空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M

64bit IO Format: %lld

## 题目描述

本题为《无尽咔咔（Easy Version）》的困难版本，两题的唯一区别在于 $x$ 和 $y$ 的范围。

邪教徒（Cultist，又名咔咔）是回合制卡牌类Roguelike游戏《杀戮尖塔》中一种类人型的怪物。咔咔在念咒后，每回合的伤害会不断增加。

![题面图片](assets/M.png)

拥有 $x$ 点生命值的玩家正在与一只已念咒的咔咔交战，玩家先手。每回合开始时，玩家可以选择一种行动：

- 攻击：对咔咔造成 $1$ 点伤害；
- 回复：玩家生命值增加 $y$ 点（无上限）。

设当前回合数为 $i$，每回合玩家行动结束时，咔咔会对玩家造成 $i$ 点伤害。

当玩家生命值小于等于 $0$ 时，游戏立即结束。即使玩家在本回合受到伤害后死亡，本回合攻击已经造成的伤害也计入答案。

玩家想知道自己最多能对咔咔造成多少伤害。

## 输入描述

第一行输入两个整数 $x,y$ $(1 \leq x \leq 10^{12},1 \leq y \leq 10^{12})$，表示玩家的初始生命值和每次回复增加的生命值。

## 输出描述

输出一个整数，表示玩家最多能够造成的伤害。

## 示例1

### 输入

```text
10 3
```

### 输出

```text
4
```

## 示例2

### 输入

```text
54321 12345
```

### 输出

```text
6177
```

## 示例3

### 输入

```text
114514 1919810
```

### 输出

```text
959905
```
