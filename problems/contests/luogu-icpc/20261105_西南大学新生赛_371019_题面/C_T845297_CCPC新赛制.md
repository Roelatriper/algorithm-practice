# C. CCPC新赛制

- 题目编号：T845297
- 原题链接：https://www.luogu.com.cn/problem/T845297?contestId=371019
- 时间限制：1000 ms
- 内存限制：512 MB

## 题目背景

为了增加比赛的悬念和观赏性，CCPC（中国大学生程序设计竞赛）引入了“动态榜单/挂气球”的新模式。比赛中不再立刻显示各队通过的题号，而是根据规则动态揭晓。

## 题目描述

当满足以下任意一个条件时，某道题目的榜单状态将“解冻（揭晓）”：
1. 通过该题的队伍数大于等于 50。
2. 通过该题的队伍数乘5大于等于参赛队伍总数。
3. 比赛时间达到或超过240分钟。

## 输入格式

第一行包含一个整数 $T$（$1 \le T \le 100$），表示测试数据组数。

接下来 $T$ 行，每行包含三个整数 $n, m, t$，分别表示参赛队伍总数、已通过某题的队伍数、当前比赛时间（单位：分钟）。


## 输出格式

对于每组测试数据，如果满足解冻条件，输出 `YES`；否则输出 `NO`。

## 输入输出样例

### 输入 #1

```text
5
100 50 0
100 20 100
100 10 239
10 2 200
10000 0 240
```

### 输出 #1

```text
YES
YES
NO
YES
YES
```

## 说明/提示

**【样例解释】**
- 第一个测试数据，通过数已达`50`，满足解冻条件。
- 第二个测试数据，通过数20乘5为100，大于等于参赛数，满足解冻条件
- 第三个测试数据通过数未达`50`，且通过数乘5小于参赛数，且当前比赛时间未达240分钟，不满足任何一个解冻条件

**【数据范围】**
对于 $100\%$ 的数据，$2 \le n \le 10^4$，$0 \le m \le n$，$0 \le t \le 300$
