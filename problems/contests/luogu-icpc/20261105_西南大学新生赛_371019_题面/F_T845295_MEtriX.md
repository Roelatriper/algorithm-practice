# F. MEtriX

- 题目编号：T845295
- 原题链接：https://www.luogu.com.cn/problem/T845295?contestId=371019
- 时间限制：1000 ms
- 内存限制：512 MB

## 题目背景

重庆市赛原题（构造）

## 题目描述

给定两个整数 $n, m$，请你构造一个 $n \times n$ 的 01 矩阵 $A$。

记第 $i$ 行的元素和为 $r_i = \sum_{j=1}^n A_{i,j}$，第 $j$ 列的元素和为 $c_j = \sum_{i=1}^n A_{i,j}$。

你需要使得矩阵 $A$ 的行和序列 $r_1, r_2, \ldots, r_n$ 的 MEX 等于 $m$，并且列和序列 $c_1, c_2, \ldots, c_n$ 的 MEX 也等于 $m$。


## 输入格式

一行两个整数 $n, m$。

## 输出格式

若存在满足条件的矩阵，首先输出一行字符串 `YES`。接下来输出 $n$ 行，每行一个长度为 $n$ 的 01 字符串，其中第 $i$ 行第 $j$ 个字符表示你填在 $A_{i,j}$ 中的元素。如果有多种合法方案，输出任意一种。  
否则，只需输出一行字符串 `NO`。

## 输入输出样例

### 输入 #1

```text
4 3
```

### 输出 #1

```text
YES
1001
0000
1100
0001
```

### 输入 #2

```text
1 1
```

### 输出 #2

```text
YES
0
```

### 输入 #3

```text
6 7
```

### 输出 #3

```text
NO
```

## 说明/提示

对于所有数据，$1 \le n \le 10^3$，$0 \le m \le 10^5$。
