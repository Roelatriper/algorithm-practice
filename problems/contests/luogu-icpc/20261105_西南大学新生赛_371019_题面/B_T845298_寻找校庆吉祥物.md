# B. 寻找校庆吉祥物

- 题目编号：T845298
- 原题链接：https://www.luogu.com.cn/problem/T845298?contestId=371019
- 时间限制：1000 ms
- 内存限制：512 MB

## 题目背景

在西南大学的校庆晚会上，有一个寻找“隐藏吉祥物”的互动环节。屏幕上会显示一串由字母和数字组成的乱码字符串，只要你能数出其中出现了多少个特定的吉祥物代号（一个字符），就能获得一份小礼品。

## 题目描述

给定一个仅包含大小写英文字母和数字的字符串 $s$，以及一个特定的字符 $c$。

请你统计并输出字符 $c$ 在字符串 $s$ 中出现的次数。

**注意：** 字符的匹配是区分大小写的（例如，`A` 和 `a` 被视为不同的字符）。


## 输入格式

第一行包含一个字符串 $s$（$1 \le |s| \le 10^5$），字符串内部不包含任何空格。

第二行包含一个字符 $c$。


## 输出格式

输出一行一个整数，表示字符 $c$ 在字符串 $s$ 中出现的总次数。

## 输入输出样例

### 输入 #1

```text
SWU2024SWU
S
```

### 输出 #1

```text
2
```

### 输入 #2

```text
swu123swu
a
```

### 输出 #2

```text
0
```

## 说明/提示

**【样例解释】**
- 样例 1 中，字符串 `SWU2024SWU` 中大写字母 `S` 出现了 $2$ 次。
- 样例 2 中，字符串 `swu123swu` 中并不存在小写字母 `a`，因此输出 $0$。

**【数据范围】**
对于 $100\%$ 的数据，保证 $1 \le |s| \le 10^5$，且字符串 $s$ 仅由大小写字母和数字组成。
