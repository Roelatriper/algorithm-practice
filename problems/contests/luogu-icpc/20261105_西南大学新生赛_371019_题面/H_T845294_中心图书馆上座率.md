# H. 中心图书馆上座率

- 题目编号：T845294
- 原题链接：https://www.luogu.com.cn/problem/T845294?contestId=371019
- 时间限制：1000 ms
- 内存限制：512 MB

## 题目背景

中心图书馆某一层有 $n$ 个座位，第 $i$ 个座位在时间段 $[a_i, b_i]$ 内被占用。

## 题目描述

现在有 $q$ 次询问，每次询问给定一个时刻 $t$，请回答时刻 $t$ 有多少个座位被占用。


## 输入格式

第一行两个整数 $n, q$。  
接下来 $n$ 行，每行两个整数 $a_i, b_i$。  
接下来 $q$ 行，每行一个整数 $t$。

## 输出格式

每个询问输出一行一个整数。

## 输入输出样例

### 输入 #1

```text
2 3
1 3
2 4
1
2
5
```

### 输出 #1

```text
1
2
0
```

## 说明/提示

**【样例解释】**

- 三次询问分别为`1`,`2`,`5`，在时刻为`1`的时候，仅有第1个座位被占用，因此输出1；在时刻为`2`的时候，两个位置都被占用，因此输出`2`；在时刻为`5`的时候，没有一个位置被占用，因此输出`0`。

**【数据范围】**
对于 $100\%$ 的数据，$1 \le n, q \le 10^5$，$1 \le a_i \le b_i \le 10^5$。
