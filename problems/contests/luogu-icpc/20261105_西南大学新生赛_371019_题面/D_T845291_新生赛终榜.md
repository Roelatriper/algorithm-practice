# D. 新生赛终榜

- 题目编号：T845291
- 原题链接：https://www.luogu.com.cn/problem/T845291?contestId=371019
- 时间限制：1000 ms
- 内存限制：512 MB

## 题目背景

比赛结束后，组委会需要生成最终排名榜。现给出每支队伍的通过题目数 $solved$ 和总时间 $penalty$。

## 题目描述

排名规则如下（优先级从高到低）：
1. 通过题目数多者排名靠前；
2. 通过题目数相同，总时间（$penalty$）少者靠前；
3. 如果均相同，那么队名字典序小者靠前。

字典序比较规则如下：
1. 逐个字符比较，从第一个字符开始，依次向后比较。字符在字母表中越靠前（ ASCII 码越小），该字符串的字典序就越小；
2. 如果前面的字符都相同，则长度更短的字符串字典序更小。

## 输入格式

第一行一个整数 $m$。  
接下来 $m$ 行，每行一个字符串 $teamname$ 和两个整数 $solved$、$penalty$，分别代表队伍名称，解题数目以及用时。

## 输出格式

输出 $m$ 行，每行一个字符串，表示按排名从高到低排列的队伍名称。

## 输入输出样例

### 输入 #1

```text
5
swu_team01 5 320
swu_team02 5 310
shiyusheng 3 450
swu_team03 3 450
suyunqiao 5 310
```

### 输出 #1

```text
suyunqiao
swu_team02
swu_team01
shiyusheng
swu_team03
```

## 说明/提示

**【样例解释】**

- swu_team02与swu_team01通过题目数量一样，但是前者用时更少，因此swu_team02排名更靠前
- swu_team02与suyunqiao通过题目数量一样，并且用时也一样，但是后者字典序更小（第二个字母u<w），因此suyunqiao排名更靠前

**【数据范围】**
对于 $100\%$ 的数据，$1 \le m \le 10^5$。  
队名只含字母、数字、下划线，长度不超过 20。  
$0 \le solved \le 13$。
