# G. 寻找校庆纪念品

- 题目编号：T845293
- 原题链接：https://www.luogu.com.cn/problem/T845293?contestId=371019
- 时间限制：1000 ms
- 内存限制：512 MB

## 题目背景

校庆期间，学校定制了 $n$ 个纪念徽章。为了方便发放，工作人员已经将这 $n$ 个徽章的编号按照从小到大（非递减）的顺序排好了序（编号可能存在重复）。

## 题目描述

小侍幸运地抽中了一张面值为$x$ 的纪念徽章兑换券。根据规则，他可以在排好序的徽章队伍中，拿走一个编号**大于等于** $x$ 且**编号最小**的徽章。如果满足条件的徽章有多个，他只能拿走排在**最前面**的那一个。

现在有 $q$ 次询问，每次给定一个面值 $x$。请你帮小西计算出他能拿到的徽章**编号**以及该徽章在队伍中的**位置**（位置从 $1$ 开始编号）。

如果队伍中所有徽章的编号都严格小于$x$（即没有符合要求的徽章），请输出$-1$。

## 输入格式

第一行包含两个整数 $n, q$（$1 \le n, q \le 10^5$），分别表示徽章的总数和询问次数。

第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$），表示排好序的徽章编号列表。保证序列是**非递减**的（即 $a_1 \le a_2 \le \ldots \le a_n$）。

接下来 $q$ 行，每行包含一个整数 $x$（$1 \le x \le 10^9$），表示一次询问。

## 输出格式

对于每次询问，输出一行。
1. 如果能拿到符合条件的徽章，输出两个整数，分别表示徽章的**编号**和它在序列中的**位置**，中间用空格隔开。
2. 如果找不到，输出 `-1`。

## 输入输出样例

### 输入 #1

```text
5 3
10 20 20 30 40
20
25
50
```

### 输出 #1

```text
20 2
30 4
-1
```

## 说明/提示

**【样例解释】**
- 询问面值为 $20$：编号大于等于 $20$ 的最小编号是 $20$，序列中有两个 $20$，位置分别是 $2$ 和 $3$，排在最前面的是位置 $2$，输出 `20 2`。
- 询问面值为 $25$：编号大于等于 $25$ 的最小编号是 $30$，位置在 $4$，输出 `30 4`。
- 询问面值为 $50$：序列中没有大于等于 $50$ 的编号，输出 `-1`。

**【数据范围】**
对于 $100\%$ 的数据，$1 \le n, q \le 10^5$，$1 \le a_i, x \le 10^9$。
