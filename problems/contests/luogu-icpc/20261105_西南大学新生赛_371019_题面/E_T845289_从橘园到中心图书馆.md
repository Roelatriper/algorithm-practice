# E. 从橘园到中心图书馆

- 题目编号：T845289
- 原题链接：https://www.luogu.com.cn/problem/T845289?contestId=371019
- 时间限制：1000 ms
- 内存限制：512 MB

## 题目背景

在做图论相关题目的时候，小侍认为西南大学校园可以看作一个 $n$ 行 $m$ 列的网格，现在他想寻找从橘园出发，寻找到图书馆的最少步数。

## 题目描述

小侍以字符串形式给出一个网格，其中 `.` 表示道路，`#` 表示施工围挡（不可通行），`S` 表示橘园宿舍入口（起点），`E` 表示中心图书馆侧门（终点）。

小侍从`S`出发，可以向上/下/左/右四个方向移动，每移动一次视为走出一步，初始步数为$0$

>注意，任何时刻小侍都不会移动到`#`上，或者移出网格边界

## 输入格式

第一行两个整数 $n, m$代表网格大小。

接下来 $n$ 行，每行一个长度为 $m$ 的字符串。

## 输出格式

输出一个数表示最少步数；无法到达则输出 `-1`。

## 输入输出样例

### 输入 #1

```text
4 5
S..#.
.##.#
.#..#
...#E
```

### 输出 #1

```text
-1
```

### 输入 #2

```text
4 5
S..#.
.##.#
.#...
...#E
```

### 输出 #2

```text
9
```

## 说明/提示

**【样例解释】**
- 样例 1 中，`E`的上下网格上均为`#`，因此`E`无法到达，输出`-1`。
- 样例 2 中，有且仅有一条路径全是`.`连通`S`到`E`，且长度为9，输出`9`。

**【数据范围】**
对于 $100\%$ 的数据，$1 \le n, m \le 1000$，保证恰有一个 `S` 和一个 `E`（不一定`S`在左上角，`E`在右下角）。
