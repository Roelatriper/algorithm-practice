# J - 争夺数字之神

来源：[牛客竞赛 141092](https://ac.nowcoder.com/acm/contest/141092/J)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒

空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M

64bit IO Format: %lld

## 题目描述

FuFuFu 和 v. 终于找到了传说中能够实现任何愿望的数字之神。然而，数字之神为了伪装自己消耗了太多法力，只能实现其中一人的愿望。

为了公平地决定谁能获得这个机会，数字之神在两人面前摆放了一堆石子，让他们进行一场取石子游戏，规则如下：

1. 这堆石子最初共有 $n$ 颗。
2. FuFuFu 先手，两人轮流从这堆石子中取走石子。
3. 每次可以取走 $1$ 颗或 $2$ 颗石子，但不能不取。
4. 取走最后一颗石子的人获胜。

两人都采取最优策略。请判断 FuFuFu 是否存在必胜策略，即无论 v. 如何行动，FuFuFu 都能保证自己获胜。

## 输入描述

输入一个整数 $n$ $(1 \le n \le 10^5)$，表示石子的初始数量。

## 输出描述

如果 FuFuFu 存在必胜策略，输出 $\texttt{YES}$；否则输出 $\texttt{NO}$。

## 示例1

### 输入

```text
2
```

### 输出

```text
YES
```

### 说明

FuFuFu 先手，直接取走全部 $2$ 颗石子即可获胜。

## 示例2

### 输入

```text
3
```

### 输出

```text
NO
```

### 说明

FuFuFu 先手，仅有两种取法：

- 如果 FuFuFu 取走 $1$ 颗石子，v. 就可以直接取走剩余的 $2$ 颗石子并获胜。
- 如果 FuFuFu 取走 $2$ 颗石子，v. 就可以直接取走剩余的 $1$ 颗石子并获胜。

因此，无论 FuFuFu 如何行动，v. 都能获胜，FuFuFu 不存在必胜策略。

## 备注
