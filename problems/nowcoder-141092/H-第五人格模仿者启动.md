# H - 第五人格模仿者启动！

来源：[牛客竞赛 141092](https://ac.nowcoder.com/acm/contest/141092/H)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒

空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M

Special Judge, 64bit IO Format: %lld

## 题目描述

庄园中正在进行一场模仿者游戏。游戏中有 $n$ 位玩家，每位玩家都只可能属于侦探团阵营或模仿者阵营。侦探团阵营的玩家永远说真话，模仿者阵营的玩家永远说假话。保证至少存在一位侦探团阵营的玩家。

每位玩家都会说一句话：“我们中有 $x$ 位侦探团阵营的玩家。”现在给出每位玩家所说的 $x$，请你帮助庄园主确定侦探团阵营的玩家数量。

保证存在满足上述所有条件的阵营划分。

## 输入描述

第一行输入一个整数 $n$ $(2 \leq n \leq 1000)$，表示玩家数量。
第二行输入 $n$ 个整数 $x_1, x_2, \dots,x_n$ $(1\leq x_i\leq n)$，表示每位玩家所说的数字。

## 输出描述

输出一个整数，表示侦探团阵营的玩家数量。
如果存在多种可能，您可以输出任意一个，系统会自动判定是否正确。注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。

## 示例1

### 输入

```text
2
1 2
```

### 输出

```text
1
```

## 示例2

### 输入

```text
3
3 3 3
```

### 输出

```text
3
```

## 示例3

### 输入

```text
4
3 1 3 3
```

### 输出

```text
3
```

### 说明

对于本样例，输出 $1$ 或 $3$ 都将被视为答案正确。
