# F - 晨跑打卡

来源：[牛客竞赛 141092](https://ac.nowcoder.com/acm/contest/141092/F)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒

空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M

64bit IO Format: %lld

## 题目描述

大学生活开始了，小新正在通过每天晨跑来保持活力。他记录了连续 $n$ 天的晨跑距离，第 $i$ 天的距离为 $a_i$ 米。

若某天的晨跑距离不少于 $k$ 米，即 $a_i \ge k$，则这一天打卡成功；否则打卡失败。连续若干天都打卡成功，称为一段“连续打卡”。

小新想知道，自己最长的一段连续打卡持续了多少天？

## 输入描述

第一行输入两个整数 $n,k$ $(1\le n\le 100, 0\le k\le 5 \times 10^4)$，分别表示记录的天数和打卡成功所需的距离。
第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n$ $(0\le a_i\le 5 \times 10^4)$，其中 $a_i$ 表示小新第 $i$ 天的晨跑距离。

## 输出描述

输出一个整数，表示最长连续打卡天数。

## 示例1

### 输入

```text
10 3000
3200 3500 2800 3000 4200 3900 2500 3100 3300 1000
```

### 输出

```text
3
```

### 说明

第 $1 \sim 2$ 天打卡成功，连续打卡天数为 $2$；
第 $4 \sim 6$ 天打卡成功，连续打卡天数为 $3$；
第 $8 \sim 9$ 天打卡成功，连续打卡天数为 $2$。
最长连续打卡天数为 $3$。

## 示例2

### 输入

```text
5 2000
1500 1800 1999 0 1200
```

### 输出

```text
0
```

### 说明

$5$ 天的晨跑距离都小于 $2000$ 米，没有任何一天打卡成功，最长连续打卡天数为 $0$。
