# 第 11 节：栈、队列与表达式状态

## 本课定位

## 唯一主要目标

面对按顺序到来的事件，能说清容器中保存什么、下一项从哪里取、何时加入或移除，并独立用栈检查嵌套括号、用队列模拟未完成任务轮转。

## 开场诊断

表达式 `([)]` 中，圆括号和方括号各有一左一右。只统计每类括号的数量，能否判断它合法？读到第三个字符 `)` 时，应检查哪个尚未闭合的左括号？先让学生说明，再引入容器与代码。

## 第一模型：多种括号匹配（栈）

- 对应练习：`../problems/course/027-bracket-expression-check/statement.md`。
- 状态：栈中按出现顺序保存尚未匹配的左括号；栈顶是最近一个尚未闭合的左括号。
- 读左括号时加入；读右括号时先判断栈是否为空，再判断栈顶类型是否匹配。若不匹配立即失败，匹配才移除；全部读完还须栈为空。
- 先用 `([)]` 排除“仅数数量”的错误模型，再用 `([])`、空串、单个右括号和未闭合左括号检查边界。
- 每个字符最多入栈、出栈一次，时间 `O(n)`，额外空间最坏 `O(n)`。

## 第二模型：任务轮转（队列）

- 对应练习：`../problems/course/028-round-robin-completion/statement.md`。
- 状态：队列从前到后保存正在等待的任务编号；队首是下一轮要处理的任务。剩余次数单独按编号保存。
- 每轮取出一个任务，完成一次；若仍未完成，放回队尾，否则把编号记入完成顺序。每轮只能处理一个队首，空队列时不能读队首。
- 先让学生手推 `n=3`、次数 `2 1 3` 的前几轮，再独立实现。检查 `n=0`、单任务一次、单任务多次、不同任务交错完成。
- 运行次数等于所有任务次数之和，时间 `O(总次数)`；队列和剩余次数空间 `O(n)`。

## 本节 C++ 语法与容器约束

- 仅用 C++03 兼容写法；`#include <stack>` 后可用 `stack<char>`，其中 `char` 是栈元素类型。`push(x)` 加入栈顶，`top()` 读取栈顶，`pop()` 移除栈顶，`empty()` 判断是否为空。`top()` 和 `pop()` 前必须确认非空。
- `#include <queue>` 后可用 `queue<int>`。队列 `push(x)` 加在队尾，`front()` 读队首，`pop()` 移除队首，`empty()` 判断是否为空；空队列不能调用 `front()` 或 `pop()`。学生以前用过队列，这里只复核操作的实际顺序。
- 括号串可用 `#include <string>` 与 `string s`；只在 `n>0` 时用 `cin >> s`，使 `n=0` 不要求额外输入。`s[i]` 取得第 `i` 个字符；首次实际使用时说明下标从0开始。
- 任务剩余次数可用 `vector<int>` 按任务编号保存。此处不引入 `auto`、范围 `for`、lambda 或新容器语法。
