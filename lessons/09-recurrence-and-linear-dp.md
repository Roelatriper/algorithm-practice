# 第 9 节：递推与线性 DP

## 本课定位

阶段 3 基础算法模型，共 2 课次。学生已经写过走楼梯的记忆化递归，能使用数组、函数和循环；本课不从术语背诵开始，而是把“一个状态依赖更小状态”的关系整理成可验证的递推程序。

本周按学生要求优先新课，不安排旧题或 H01 的轻微迁移；这些延迟任务保留，不记为完成，也不作为 009 的开课门槛。

## 唯一目标

面对一个基础递推或线性 DP 问题，能够在写代码前完整写出四项：`dp` 状态的含义、状态转移、初始状态、计算顺序，并据此实现和测试程序。

## 开课诊断

读取 `../problems/course/000-initial-diagnostic/dp.cpp` 中已有的走楼梯记忆化递归，不改代码，先回答：

1. `js(i)` 返回值的准确含义是什么？
2. `js(i)` 与前两个更小状态有什么关系？
3. `i=0`、`i=1` 为什么必须单独处理？
4. 数组 `a` 保存什么；如果改成从小到大计算，最先应算哪些下标？

诊断只检查前置模型，不算旧题迁移，也不要求重写原程序。

## 第 1 课次：从记忆化递归到一维 DP

1. 把函数返回值改写为明确的状态句子，例如“`dp[i]` 表示到达第 `i` 级台阶的最小总代价”。
2. 区分题目中的数据与状态：`cost[i]` 是已知代价，`dp[i]` 是由更小问题算出的最优答案。
3. 由最后一步来自哪里推导转移，不先背公式。
4. 单独确定不能由通式安全覆盖的初值，再按依赖方向从小到大计算。
5. 独立完成“带代价上楼梯”，并用手算表格核对每个状态。
6. 比较记忆化递归和自底向上递推：两者状态和转移相同，执行顺序与函数调用开销不同；本课先保证数组版正确，不急于压缩空间。

## 第 2 课次：二维状态与边界

1. 从一维“到达位置 `i`”扩展到二维“到达格子 `(i,j)`”。
2. 由最后一步只能来自上方或左方推导转移。
3. 分开处理起点、第一行和第一列，避免访问负下标。
4. 独立完成“网格最小路径代价”，再解释为什么按行从上到下、每行从左到右可以得到已知前驱。
5. 对照一维和二维题，确认改变的是状态坐标，不是 DP 的四项分析框架。

## C++ 语法

全程使用 C++03 兼容语法。继续使用普通数组或 `vector<long long>`、下标循环和 `long long`；首次使用二维 `vector` 时解释外层表示行、内层表示列，以及 C++03 中嵌套模板的两个右尖括号之间要留空格。本课不使用 `auto`、范围 `for`、lambda 或其他 C++11 语法。

## 测试要求

- 一维题至少覆盖 `n=1`、`n=2`、连续选择一步、需要跨两步、代价为 0 和答案超过 `int` 的情况。
- 二维题至少覆盖 `1x1`、单行、单列、最优路径多次转向和较大代价。
- 每组测试给完整输入、完整预期和用途；先手算小规模 `dp` 表，再运行程序。
- 教师补充的测试与学生自主测试分开记录。

## 过关标准

- 写代码前能准确给出状态含义、转移、初值和计算顺序。
- 独立完成一维与二维各 1 道基础 DP，且下标边界合法。
- 能说明转移为什么枚举了最后一步的所有可能来源。
- 能用手算状态表定位至少一个错误，而不是只对照最终输出。
- 完成主动测试、24 小时闭卷重写和 7 天轻微迁移后，再按通用评分判断掌握。
