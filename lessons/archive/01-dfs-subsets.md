# 历史学案：DFS 枚举子集

> 来源：2026-08-24 算法小讲堂。此题当时未独立完成，仓库根目录 `DFS枚举子集.cpp` 是课后整理版，不作为已掌握证据。

## 题目

给定 `N` 个互不相同的数，输出全部子集的元素和。

对每个元素都有“选”和“不选”两种选择，因此全部组合形成一棵深度为 `N` 的二叉递归树。

## 状态设计

- `idx`：当前处理第几个元素。
- `sum`：此前已经选择的元素之和。
- 终止条件：`idx == n`，此时输出一个完整选择对应的 `sum`。

两条递归分支：

```cpp
dfs(idx + 1, sum + arr[idx]); // 选
dfs(idx + 1, sum);            // 不选
```

## 复杂度

共有 `2^N` 个子集；仅输出每个子集的和时，时间复杂度为 `O(2^N)`，递归栈空间为 `O(N)`。
