# 历史学案：区间调度贪心

> 来源：2026-08-24 算法小讲堂。学生原始代码位于仓库根目录 `区间调度贪心.cpp`。

## 题目

一次只能处理一个客户，每个客户占用 `[开始, 结束)` 区间，求最多能够选择多少个互不重叠区间。

## 贪心策略

按结束时间升序排序，从前向后扫描。只要当前区间的开始时间不早于上一个已选区间的结束时间，就选择当前区间。

直觉是：当前结束越早，给后续区间留下的可用空间越大。

## 正确性：交换论证

考虑任意一个最优方案的第一个区间。将它替换为所有候选中结束最早的区间，不会让后续可选空间变小，也不会减少方案数量。固定第一个选择后，剩余部分仍是同样的区间调度问题，因此可以重复这个论证。

## 复杂度

- 排序：`O(n log n)`。
- 扫描：`O(n)`。
- 总时间：`O(n log n)`。

## 学生原实现的评价

原实现已经正确表达了“按结束时间排序索引，再扫描选择”的主体逻辑。主要待改进点是：

- `int array[n+1][2]` 是编译器扩展，不是标准 C++17 变长数组写法。
- `n = 0` 时仍会输出 `1`。
- 尚未提供系统测试和能击穿错误贪心策略的反例。
- 需要使用 `vector`、`struct` 与 `sort` 完成标准重写。
