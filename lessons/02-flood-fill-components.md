# 第 2 节：洪水填充与连通块

## 本课定位

承接迷宫 BFS，用已经接触过的四方向搜索学习统计连通区域。只用 C++03 兼容语法。本课不替代 10-09 的闭卷重写或 10-15 起的无提示延迟验证。

## 本次目标

给定地图，统计所有可走格子组成的连通块数量，完成完整程序与自主测试。

`.` 表示可走格子，`#` 表示墙，只能上下左右移动。能沿可走格子互相到达的格子属于同一个**连通块**。只在角上接触不算相连。

**洪水填充（flood fill）**是从一个格子开始，把与它相连的同类格子都访问到的搜索方法；可以用已经学习的 BFS 实现。

## 开课回忆与建模

先不写代码，观察这张 4×5 地图：

```text
..#..
.##..
###.#
..#..
```

1. 有多少个连通块？说明各块的位置。
2. 只从左上角做一次 BFS，能访问所有 `.` 吗？为什么？

先收学生解释，再按提示阶梯推进整个地图的处理方法、计数时机和访问标记。此处不预先提供完整方案或代码。

## 口述后的模型澄清

本图左上区域有 3 个格子，右侧区域有 7 个格子，左下区域有 2 个格子，总共是 **3 个连通块**。区域面积与区域个数是两种计数。

扫描地图时，只有遇到尚未访问的 `.` 才需要启动一次 BFS，并让连通块数量增加 1。这次 BFS 要把与起点连通的整片区域标记完，直到队列为空。后续扫描到同一区域的其他格子时，它们已经有标记，不会再计数。

访问标记由整张地图共用，保留各次搜索的结果。它在此题中的含义是：这个格子所属的区域已经被处理。一个新区域对应一次搜索，而不是每个格子都对应一次新的搜索。

以上为学生提出“标记并搜索所有的 .”之后的 2 级模型帮助；尚未给完整代码或代码骨架。

## 两层处理：谁找到下一片区域

外层由 main 在读完地图后逐行逐列扫描所有坐标，内层 BFS 从外层选出的起点标记完整片区域。BFS 返回后，外层循环继续处理下一个坐标，不需要从头重扫，也不清空全图访问标记。

外层伪代码（10-09 补充，3 级帮助；全轮此前已到 4 级）：

```text
区域数 = 0
遍历地图中的每个格子 (i, j)：
    如果它是 . 并且尚未访问：
        区域数加一
        从 (i, j) 启动 BFS，标记完整片区域
输出区域数
```

例如一行 `.#.`：从第一个点 BFS 返回后，外层继续扫描，跳过墙，在最后一个未访问点启动第二次 BFS。访问标记使同一区域的其他格子不会再次触发搜索。

先由学生实现读图后的外层扫描与计数，再完成单区域 BFS，不预先给整题参考实现。

## 10-09 扩展：每块区域的格子数

学生明确扩展输出为区域总数，以及各块面积，当前题面已同步。因此单区域 BFS 返回格子数是合理接口；此前只统计区域总数时使用 void 的建议不再是要求。

面积统计从起点的 1 个格子开始，每发现一个未访问的新格子再增加 1，保持每格只计数一次。格子数量与离起点的距离是不同状态。

输出结果时要保证每个保存的面积都输出一次。每次 pop 后结果队列 size 会变化，不能把不断缩小的 size 与不断增大的循环下标直接比较来控制输出；队列为空时也不能调用 front。
