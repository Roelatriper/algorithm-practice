# 学生画像

> 本文件只记录相对稳定的信息。单次表现和下一步任务写入 `STATE.md` 或 `sessions/`。

## 基本背景

- 称呼：白衣。
- 2026 级本科新生；现有资料显示就读西南大学软件工程相关中外合作项目。
- 长期方向：提升计算机基础与算法竞赛能力，为大学竞赛、专业学习和保研机试打基础。
- 主语言：C++。竞赛训练期间以 C++ 为唯一主语言，其他语言作为旁支处理。
- 日常设备：MacBook，常规编程与算法训练在本地完成。
- 宿舍设备：Windows 台式机，编译环境主要位于 WSL；较大项目时可从 MacBook 经 SSH 使用。

## 当前能力基线

### 已有基础

- 能使用循环、数组、函数、结构体雏形和简单递归。
- 能完成走楼梯的记忆化递归。
- 理解 DFS“选/不选”模型的直观含义。
- 区间调度实现已能组织“排序索引 + 贪心扫描”的多步逻辑。

### 当前短板

- STL 尚未在本人代码中稳定使用，尤其是 `vector`、`string`、`queue` 与自定义排序。
- 容易在 EOF、`null`、未知长度输入和空数据上停滞。
- BFS 尚未形成队列、访问标记、合法性判断和最短路层次的完整模型。
- 树题同时欠缺指针初始化、层序建树、空结点处理和递归边界。
- 系统调试能力不足，尚未形成编译警告、最小反例、边界测试和状态跟踪的固定流程。
- 能理解部分思路，但把思路独立转化为完整、正确程序的成功率较低。

## 学习特点

- 题目跨度过大或连续失败时容易沮丧；反馈应具体指出已经做对的部分与下一处可控改进。
- 纯粹长时间硬想的收益较低，适合限时独立尝试后逐级领取提示。
- “看懂参考代码”容易造成掌握错觉；必须通过闭卷重写、延迟复习和同模型迁移题确认。
- 对自己的卡点有一定反思能力，适合培养结构化复盘习惯。

## 教学约束

- 学期中 GPA 优先；学生于 2026-09-24 锁定常态每周 12 小时算法训练。党务或考试繁忙周以 8 小时为保底，短期极忙可降到 5～6 小时维持；若连续两周低于 8 小时，应主动调整低优先级课程范围。2027 年 2 月全长模拟阶段目标约 14 小时。
- 学生要求今后的授课与示例代码默认使用 C++11 以前的语法（以 C++03 兼容为准）；除非学生另行同意，不引入 C++11 及更新版本的语法。现有构建脚本使用 C++17，不代表授课必须使用 C++17 语法。
- 新语法首次出现时解释其目的，不把 STL API 当作已熟练知识。
- 评价重点依次为：建模、完整实现、正确性验证、调试、迁移。
