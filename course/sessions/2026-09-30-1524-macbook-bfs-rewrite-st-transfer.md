## 诊断

- 已经做对：能够闭卷搭出队列、四方向、边界、距离和入队访问标记；能将固定起终点迁移为读图记录 `S`、`T`；理解二维 `vector` 的外层是行、内层是列，并能说明同一父节点的所有孩子都应使用 `cur.step + 1`。
- 第一处关键错误：闭卷重写中在 `while (!queue.empty())` 结束后又判断 `if (!queue.empty()) return -1`，使不可达路径走到非 `void` 函数末尾而无返回值。后续还出现终点行列颠倒、`1×1` 返回 `1`、迁移订正版把 `visited` 声明为只读引用且忘记给新节点做入队标记。
- 错误类别：实现 / 边界 / 调试 / 参数语义。
- 最小反例：`2 2 / .# / #.` 暴露不可达返回缺失；`1 2 / ..` 暴露终点行列颠倒；`1 1 / .` 暴露零步距离；`4 4 / S... / .... / #### / ###T` 暴露未维护访问标记导致有环区域无法耗尽。
