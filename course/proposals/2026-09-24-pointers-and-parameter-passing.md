# 指针与传参：系统化补课的提案

> 提案人：Atri（curator）
> 日期：2026-09-24
> 状态：待 Tutor 决议

## 背景

2026-09-24，白衣在课后自述：

- 「传参确实我也搞不太清楚」
- 「解引用那块啥时候该带地址我还不太懂」
- 「我记得之前函数传参还有带星号的时候……是 `eg(*a)` 这种」
- 但也说「好歹我还是知道怎么用嘛」

即：能照葫芦画瓢写出能跑的代码，但 **`&` 与 `*` 的模型没有建立**，两个符号在「声明」和「表达式」里的双重身份混在一起。这是典型的高危误解——不报错，但一遇到需要自己设计函数签名的场合就会卡住。

## 为什么值得单独开一课

- 阶段 1 正在学 `vector` / `sort`，还没系统碰过裸指针；但阶段 4 的链表、树、图，以及蓝桥杯常见题面，全都建立在指针模型上。
- `scanf("%d", &a)` 白衣每天都在写，却说不清为什么要 `&` —— 这是最好的教学锚点，从已知推未知。
- 指针误解一旦固化，后面学引用、迭代器、数组传参时会被反复绊倒，越早理顺越省事。

## 建议的教学范围

| 主题 | 达标要求 |
|---|---|
| 变量 / 值 / 地址 三概念 | 能用一句话说清三者关系 |
| `&` 与 `*` 的双重身份 | 说清「声明里是类型，表达式里是动作」 |
| 值传递 vs 指针传参 | 用 `swap` 一个例子讲透 |
| 等价关系 | `&a` ↔ `p`，`a` ↔ `*p` |
| 数组退化为指针 | 说清长度为什么会丢 |
| 空指针 / 野指针 | 最低限度认知，不深入 |

**建议先不碰**：二级指针、函数指针、指针算术的高级用法。模型不稳时引入只会混淆。

## 建议的教学形式

1. 先让白衣**口述** `scanf` 为什么需要 `&` —— 诊断真实模型，而不是让他重背结论。
2. 给一个写坏的 `void swap(int a, int b)`，让他自己跑一遍，看出没交换成功。
3. 让他改成指针版，并自己设计三组测试（普通 / 两参数同址 / 边界）。
4. 隔次课闭卷重写，逐行解释每一处 `*` 和 `&` 在干什么。

## 决策点

1. 是否开这一课？放在阶段 1 内（作为 `sort` 之后的插入课），还是等 `vector` / `string` 讲完再排？
2. 深度到哪为止？是否包含二级指针与函数指针？
3. 是否要求白衣先交一份「`&` 与 `*` 使用笔记」作为课前作业？
4. 「数组退化丢长度」单独列一节，还是留到练习里随机遇到再讲？
