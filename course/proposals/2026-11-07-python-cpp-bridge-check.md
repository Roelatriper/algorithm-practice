## 三、请 Tutor 整理的内容范围

整理方式：以 C++ 为参照，只保留 Python 新写法、规范、语义差异，以及 C++ 中存在而 Python 不直接这样使用的特性。不要从「什么是函数、循环、继承」开始重教；不要把库 API 更名说成新的算法概念。

建议在已有 `python-learning/` 内组织，具体文件结构由 Tutor 决定，Curator 不先建教学笔记。内容应能覆盖：

1. **语法外壳与规范**：冒号和缩进、`elif`、`#`、`pass`、括号内续行；类型绑定与可选类型提示；三引号字符串和 docstring 的区别。
2. **类型和运算**：`True/False/None`、整数任意精度、字符串无独立 char、复数；`/` 与 `//`、负数取模、`**` 与异或、`and/or/not` 的短路与返回操作数；真值、链式比较、`in`、`==` 与 `is`。
3. **序列写法**：负索引、左闭右开切片、字符串不可变、原始字符串；解包、星号收集/展开、交换与多返回值；推导式中表达式和循环的关系。
4. **容器**：list/tuple/dict/set/frozenset 的定位与基本操作；`{}` 是空字典、空集合用 `set()`；dict 缺键访问不自动插入、默认遍历键、items/values、插入顺序与可哈希要求；列表原地修改方法通常返回 None。
5. **对象模型**：所有普通赋值都是名字绑定；可变对象原地修改与名字改绑；浅拷贝与嵌套共享；二维列表的共享行陷阱；`+=` 对内置整数和列表的差异，不能通用地等同于 `a = a + b`。
6. **遍历**：`range`、`enumerate`、`zip`；循环 else 表示正常结束且没有 break，continue 不会阻止最终 else，return 或异常离开则不同。工具等效示例用于解释行为，不宣称编译器会直接展开成某段 C++ 循环。
7. **函数**：`def` 的执行时序、关键字/默认参数、`*args/**kwargs`、默认值求值时机；参数共享对象而非 C++ 普通引用绑定；返回新值与修改共享状态；函数局部、模块 global、外层函数 nonlocal。
8. **类与资源**：self、初始化方法、实例属性/类属性、super、staticmethod、动态方法查找、下划线约定；没有 C++ 式强制访问分区；`__del__` 不保证作用域退出立即清理，del 名字不等于立即销毁对象。
9. **输入输出**：input 返回字符串、显式转换、split/map/list、print 参数和 f-string；with open、str/bytes、文件模式和编码；文件操作库只需 API 对照，删除不是自动送回收站。
10. **C++ 习惯迁移**：无自增/自减、三段式 for、原生 do-while、普通 int& 参数、指针算术和 new/delete 写法；条件表达式写成 `a if cond else b`；同名普通 def 不按签名重载；match 是模式匹配而非 C++ switch 的同构替换。不要误说位运算、运算符重载、泛型能力或旧 `%` 字符串格式化已经被删除。
11. **少量内置函数差异**：divmod 返回整除商与余数；整数 pow 三参数模幂；round 的中点取偶与二进制浮点近似必须分开讲。

上述清单是整理范围，不要求逐项拉长口头考试；优先检查下面真实暴露出的混淆点。

## 四、本轮具体疑问与下次优先抽查点

以下按学生真实追问归并；都是待复查线索，不是确认仍然不会，也不是已掌握证据。

### 1. 字符串、类型和符号

- 三引号为什么不是多行注释？docstring 放在什么位置、有什么可读取的效果？
- 曾把 is 理解成比较类型。请让学生区分内容相等、同一对象、同一类型，并解释 None 判断。
- 曾把 `first, *middle, last = ...` 的星号联想到指针。请预测 middle 的内容和类型，并区分乘法、重复、收集、调用展开。
- 曾把 set 理解成变量预声明。请区分空列表、空字典、空集合；说明 set 是容器。

### 2. 推导式、二维列表与共享

- 曾把 `[x*x for x in ...]` 的 `x*x` 联想到二维数组；需能把简单推导式展开为 append 循环，并说明表达式结果如何进入一维列表。
- 需区分二维单元素赋值/乘法、所有元素数乘与列表重复。无需引入 NumPy 作为本轮前置。
- 问过共享是否只发生在列表；后续已能用「类似两个指针指向同一地址」描述别名，但又把不可变理解成变量受 protected 保护。重点检查：不可变的是对象，不限制名字重新赋值；`a = ...` 改绑与 `a[0] = ...` 改内容。
- `[[0]*m for _ in range(n)]` 中 `_` 只是不用其值的普通变量约定，防共享来自每次创建新行；对比 `[[0]*m]*n`。
- 学生将行为差异解释为编译器展开。需检查其能否说明「不同类型的运算语义不同」，不只背一句编译器会换写法。

### 3. 传参、遍历和函数

- 要改变外部整数通常返回再赋值；要改共享列表内容则原地修改。不要笼统说所有参数按 C++ 引用传递。
- enumerate 和 zip 曾重复追问。让学生自己逐轮列出拿到的二元组、循环变量如何解包，以及 zip 长度不同时停在哪里；只会认名字不算理解。
- 学生已询问 continue 是否仍执行循环 else，并认为 else 可用 found 标记替代。认可两种实现；不把喜好某种语法作为过关条件。
- def 不必在所有执行语句之前，但实际调用时需要名字已绑定；函数体里的另一个函数名可以晚于当前 def、早于实际调用绑定。
- 默认列表参数与函数体内创建空列表的区别仍需预测多次调用；核心是定义执行一次与函数体每次调用执行，而非「定义域/作用域」。
- nonlocal 作用于最近的已有外层函数绑定，不特指 main；与模块级 global 区分。嵌套函数不是本轮编码题的硬要求。

### 4. round 与浮点数

- 学生质疑「中点应等距」「无限循环 9 应等于中点」。数学上无限循环 9 等于目标中点这一点应认可。
- 必须区分：输入的精确十进制数、存储的有限精度二进制浮点值、输出格式显示位数。固定浮点对象的精确值不会因多问几次而变化。
- 教师侧已实际运行：`Decimal.from_float(2.675)` 为 `2.67499999999999982236431605997495353221893310546875`，是有限小数，不是无限循环 9；`round(2.675, 2)` 为 2.67。
- 从字符串构造 `Decimal('2.675')` 可精确保留该十进制输入；其保留两位、中点取偶为 2.68。不要从已经近似的 float 构造后宣称还原原始十进制输入。
- 中点取偶针对真正中点；上述 float 已在中点以下。减少累计舍入偏差是动机，不保证任何分布都无偏。这不是 Python 独有的浮点问题，常见 C++ double 也受同类表示限制。
- 不要求学生记住精确尾数，也不把这些教师运行结果记录为学生自行执行或预测。
