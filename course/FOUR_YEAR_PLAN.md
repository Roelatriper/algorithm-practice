# 白衣的大学四年规划（最终版）

> 基于2026-09-14 grilling session
> 目标：保研985（浙大/南大冲刺）
> Plan B：奥克兰大学研究型硕士（~13万人民币/年）

## 大一（2026.9 - 2027.7）

### 上学期（当前）
- [ ] **绩点拉满**：高数、线代、C语言认真学，大一绩点最容易拿
- [ ] **蓝桥杯报名**：明年4月比赛，现在开始准备
- [ ] **进校队**：预计2027年3月参加校队选拔网赛（寒假公布确切信息），作为当前算法训练的第一硬截止日期
- [ ] **四级**：12月或明年6月考
- [ ] **刷算法**：洛谷入门题 + CF 800-1200，每天1-2小时

### 下学期
- [ ] **蓝桥杯参赛**：试水，积累比赛经验
- [ ] **物色实验室**：了解学院老师的研究方向，找感兴趣的导师聊
- [ ] **四级通过**

### 每周自由时间：约30-35小时（周六日无课）
- 周一：9:40-12:10 + 15:40后
- 周二：9:40-14:00
- 周三：9:40-14:00 + 16:35-19:20
- 周四：11:40-14:00 + 15:40-19:20
- 周五：上午 + 14:00-19:20（工程伦理7周后全天自由）
- 周六日：全天空闲
- 算法练习：常态锁定12小时；党务或考试繁忙周保底8小时，2027年2月选拔冲刺期约14小时
- 课内复习+作业：8-10小时
- 英语：3-4小时
- 其余：机动

## 大二（2027.9 - 2028.7）

- [ ] **ICPC正式参赛**：校赛选拔 → 区域赛
- [ ] **六级**：大二上考
- [ ] **进实验室**：大二正式进组，开始接触科研
- [ ] **保持绩点**：专业课（数据结构、操作系统等）不能松
- [ ] **继续刷算法**：CF冲蓝名（1600+）

## 大三（2028.9 - 2029.7）

- [ ] **科研出成果**：争取一篇论文或有实质进展的项目
- [ ] **ICPC最后一年参赛**：拿高奖
- [ ] **保研准备**：
  - 大三下关注浙大/南大夏令营
  - 准备简历、研究计划、面试
  - 了解目标导师的研究方向
- [ ] **Plan B准备**：如果考虑奥克兰，大三考雅思（6.5+）

## 大四（2029.9 - 2030.7）

- [ ] **保研确认** 或 **考研冲刺**
- [ ] **毕业设计**
- [ ] **如果保研成功**：提前学习研究生方向基础知识

## 保研加分项排序

1. **成绩**（底线，占大头）
2. **竞赛**（ICPC高奖 > 蓝桥杯国奖）
3. **科研**（论文/项目经历）
4. **英语**（六级高分是加分项）

## 备注

- 中外合作办学课程较多，自由时间有限，算法练习别贪量
- 保研率约10-20%，三件套（成绩+竞赛+科研）都得上
- 奥克兰研究型硕士学费只有授课型的1/4，如果走这条路性价比更高
- 方向不锁死，大二根据学习体验再定
